01 / What it does

Simple tool.
Useful output.

Piestructure is deliberately focused. It gives you a quick way to understand what is inside a project without turning the process into another project of its own.

01

Recursive trees

Walk through nested folders and files and produce a familiar tree layout that is easy to scan in a terminal.

project/
├─ src/
│ └─ app.py
└─ README.md
02

Exclude what gets in the way

Leave large or irrelevant paths out of the generated structure. Pass multiple paths as a comma-separated list.

node_modules.gitbuild
03

Keep a copy

Save a generated structure into the project's exports directory as a plain text file.

.txt project-structure.txt
04

Made for real terminals

Colorama handles Windows terminal color support while the core directory logic stays portable across major desktop platforms.

WINLINMAC
02 / The workflow

From folder
to structure.

01

Point it at a directory

Give Piestructure the folder you want to inspect. User paths are expanded before the directory is processed.

02

Choose exclusions

Skip paths that make the output noisy, such as dependency folders, generated builds, or version-control data.

03

Display or export

Print the result immediately, save it to a text file, or do both. The output stays plain and portable.

03 / Get started

Small setup.
Immediate output.

Clone the repository, install its only third-party dependency, and run the script. There is no build system or framework to configure.

Open repository ↗
terminalsetup
# clone
git clone https://github.com/ADevNamedDeLL/Piestructure.git
cd Piestructure

# install dependency
pip install colorama

# run
python Piestructure.py
